⚙️ 배포 전 설정이 필요해요

이 파일은 Firebase(무료 클라우드 DB)를 연결해야 학생들과 실시간으로 데이터를 공유할 수 있습니다. 아래 순서대로 5~10분이면 설정을 마칠 수 있어요.

  1. 1. Firebase 콘솔에서 무료 프로젝트를 새로 만듭니다.
  2. 2. 왼쪽 메뉴 Firestore Database → "데이터베이스 만들기" → 프로덕션 모드로 생성합니다.
  3. 3. 왼쪽 메뉴 Authentication → "시작하기" → 로그인 방법에서 이메일/비밀번호를 사용 설정합니다. 이후 "Users" 탭에서 선생님 본인 이메일/비밀번호로 계정을 1개 만드세요. (회원가입 화면은 따로 없습니다 — 보안을 위해 콘솔에서 직접 만듭니다)
  4. 4. 프로젝트 설정(⚙️) → "내 앱" → 웹 앱 추가 후 나오는 firebaseConfig 값을 이 파일 하단 스크립트의 firebaseConfig와 TEACHER_EMAIL에 붙여넣습니다.
  5. 5. Firestore → "규칙" 탭에서 아래 규칙을 붙여넣고 게시합니다. (아래 TEACHER_EMAIL 부분을 3번에서 만든 이메일로 바꿔주세요)
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isTeacher() {
      return request.auth != null && request.auth.token.email == "TEACHER_EMAIL";
    }
    match /schedules/{doc} { allow read: if true; allow write: if isTeacher(); }
    match /notices/{doc}   { allow read: if true; allow write: if isTeacher(); }
    match /settings/{doc}  { allow read: if true; allow write: if isTeacher(); }
    match /students/{doc}  { allow read, write: if isTeacher(); }
    match /customPages/{doc} { allow read: if true; allow write: if isTeacher(); }
  }
}

설정을 마친 뒤 파일을 저장하고, GitHub Pages / Netlify / Firebase Hosting 등 아무 정적 호스팅에 올리면 공개 링크와 QR코드가 생깁니다. (관리자 탭에서 링크·QR 확인 가능)
